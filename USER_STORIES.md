# Unifora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief data officer

- As a CDO, I want every AI use case tied to stewarded datasets, so that we stop launching models on shadow extracts.
- As a CDO, I want a dashboard of wrangling-time share and quarter TTV, so that I can prove the Finextra diagnosis is being fixed.
- As a CDO, I want LOB sharing disputes escalated with deadlines, so that fiefdoms cannot pocket-veto by silence.

### AI project lead

- As an AI project lead, I want a checklist-driven readiness score before sprinting models, so that we do not burn a quarter discovering missing lineage.
- As an AI project lead, I want reusable cleansed products for AML or customer-service features, so that each project is not 80% prep again.
- As an AI project lead, I want pipeline SLA status, so that “done” means monitored production—not a notebook.

### Data steward

- As a steward, I want share requests with purpose and retention, so that I can approve safely.
- As a steward, I want quality rules and incident tickets, so that consumers cannot claim ignorance of broken feeds.

### Model ops engineer

- As a model ops engineer, I want algo pipelines registered with patch/update cadences, so that hundreds of models do not become unowned.
- As a model ops engineer, I want capacity views across concurrent AI projects, so that we schedule retrain storms.

### Risk / compliance data officer

- As a compliance officer, I want lineage for AML and regulatory extracts, so that false-positive reduction gains do not destroy evidential trails.
- As a compliance officer, I want third-party share scenarios distinguished from internal federation, so that PSD2/GDPR tensions are explicit.

### LOB CIO

- As a LOB CIO, I want visibility into who consumes our data and for what purpose, so that federation is not confiscation without accountability.
- As a LOB CIO, I want to deny requests with recorded rationale, so that legitimate confidentiality survives—and unjustified denials are challengeable.
